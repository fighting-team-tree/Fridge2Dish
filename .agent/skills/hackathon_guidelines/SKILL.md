# Gemini 3 Global Hackathon Guidelines

> **Source**: https://gemini3.devpost.com/  
> **Host**: Google DeepMind & Devpost  
> **Total Prize**: $100,000 USD

---

## 핵심 정보 요약

| 항목 | 내용 |
|------|------|
| **총 상금** | $100,000 USD |
| **핵심 요구사항** | Gemini 3 API를 활용한 **새로운** 애플리케이션 |
| **제출물** | 텍스트 설명(~200자), 공개 프로젝트 링크, 코드 저장소, ~3분 데모 영상 |

---

## 심사 기준 (Judging Criteria)

| 기준 | 비중 | 설명 |
|------|------|------|
| **Technical Execution** | 40% | 품질 높은 개발, Gemini 3 활용도, 코드 품질 및 기능성 |
| **Innovation / Wow Factor** | 30% | 아이디어의 참신성과 독창성, 문제 해결의 독특함 |
| **Potential Impact** | 20% | 실제 세계에서의 영향력, 사용자 유용성, 문제 해결 효율성 |
| **Presentation / Demo** | 10% | 문제 정의 명확성, 솔루션 프레젠테이션, 문서화/아키텍처 다이어그램 |

---

## ⚠️ 피해야 할 프로젝트 유형

> **Action Era**: 단일 프롬프트로 해결되는 것은 애플리케이션이 아님

| 유형 | 이유 |
|------|------|
| **Baseline RAG** | Gemini 3 Pro는 1M 토큰 컨텍스트 윈도우로 기본 기능화됨 |
| **Prompt Only Wrappers** | 기본 UI에 시스템 프롬프트만 추가한 앱 |
| **Simple Vision Analyzers** | 기본 객체 식별은 구식; 시공간적 비디오 이해 필요 |
| **Generic Chatbots** | 영양, 채용 심사, 성격 분석용 표준 봇 |
| **Medical Advice** | 의료/정신건강 진단 조언 생성 프로젝트 금지 |

## 추천 전략 트랙 (Strategic Tracks)

### 🧠 The Marathon Agent
- 수시간~수일에 걸친 자율 시스템 구축
- Thought Signatures와 Thinking Levels로 연속성 유지
- 인간 감독 없이 다단계 도구 호출에서 자체 수정

### ☯️ Vibe Engineering
- Google AI Studio Build 탭 및 Antigravity 활용
- 코드 작성뿐 아니라 자율 테스팅 루프와 브라우저 기반 검증으로 확인

### 👨‍🏫 The Real-Time Teacher
- Gemini Live API로 라이브 비디오/오디오 합성
- 적응형 학습 구현

### 🎨 Creative Autopilot
- Gemini 3 추론 + Nano Banana Pro 결합
- 고해상도, 지역화된 Paint-to-Edit 컨트롤
- 읽기 쉬운 텍스트가 포함된 전문적 브랜드 일관성 자산 생성

## FAQ

### Q1: Gemini 3 무료 티어 접근 방법?
AI Studio에서만 무료 티어 사용 가능. [Rate Limits](https://ai.google.dev/pricing) 참조.

### Q2: 심사위원과 테스트 로그인 공유 가능?
✅ 가능 - "Testing Instructions" 제출 양식 활용. 단, **공개 AI Studio 링크 또는 공개 코드 저장소는 필수**.

### Q3: 참가 인증서 제공?
❌ 없음
